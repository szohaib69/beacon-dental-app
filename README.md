# Smile Studio Pro

Build a modern, premium, professional dental clinic website for a dental practice in the United States.

The website should feel like a high-end US healthcare brand: trustworthy, clean, welcoming, modern, family-friendly, and conversion-focused. It must NOT look like a generic template or an AI-generated website.

IMPORTANT:

Build the website as a fully responsive production-quality web application.

Mobile-first design.

Optimize for desktop, tablet, and mobile.

Use clean component architecture.

Use TypeScript.

Use modern React.

Use Tailwind CSS.

Use subtle animations and micro-interactions, but avoid excessive animations.

Prioritize accessibility, performance, SEO, and conversion.

Do not use lorem ipsum.

Use realistic dental clinic content throughout.

All clinic information should be easy to replace later through clearly structured data/constants.

Do not invent real doctors, addresses, phone numbers, certifications, reviews, or insurance partnerships. Use clearly marked placeholder/demo information where necessary.
